Homepathy

Live siteMar 2025 – Apr 2026 · Lead developer

An online homeopathy consultation platform. Patients find a doctor, book a slot, pay, and join a video consultation in the browser. Doctors and admins get their own logins. I was the lead developer, with 50 of the project's 69 commits; two other developers contributed the rest.

What it does

  • Doctor listings with filters, doctor profiles and treatment categories.
  • Booking with patient details, then Razorpay checkout.
  • Video consultations in the browser, in a private room for each appointment.
  • Separate sign-in for patients and doctors, and a protected admin area.
  • An admin panel for doctors, appointments, patients and settings, plus a blog CMS with categories.

How it is built

App
Next.js App Router, React, TypeScript, react-hook-form with Zod validation, Radix UI.
Data
Supabase tables for doctors, appointments, patients, payments, blog posts and categories.
Video
LiveKit. The server mints an access token scoped to one room with a 30-minute lifetime, so a token stops working once the consultation window is over.
Payments
Razorpay. The server recomputes the HMAC-SHA256 signature of order_id|payment_id with the secret and rejects any mismatch before the appointment is confirmed.
Auth
NextAuth and Firebase Authentication; doctor-based authentication; middleware-protected admin routes.

The hard part

Making payment and video trustworthy without trusting the browser. The client only ever receives a payment result and a short-lived room token. Whether a payment is valid, and who may enter which room for how long, is decided on the server.

Status and limits

  • The code is in a private repository, so there is no public code link.
  • I haven't published usage or consultation numbers.
  • The live site may have changed since my last commit in April 2026.

Habito, a habit tracker

Code on GitHubMar 2025 · Solo project

A cross-platform habit tracker in React Native and Expo. You create habits on a daily, weekly or monthly rhythm, check them off, watch your streaks on a chart, and get a local reminder when it's time.

What it does

  • Create, edit and track daily, weekly or monthly habits, each with its own icon and colour.
  • Streaks and progress charts for every habit.
  • Customisable local reminders through Expo Notifications.
  • A daily motivational quote, onboarding for first launch, and light, dark or system theme.
  • Export and import of habit data for backups.

How it is built

App
React Native with Expo and TypeScript; React Native Paper for Material components; Reanimated for motion.
State
Redux Toolkit, with one slice for habits and one for app settings.
Storage
A storage service over AsyncStorage persists the store on the device.
Navigation
React Navigation: a root stack for onboarding and forms, bottom tabs for Home, Progress, a central Add button and Settings.
Charts
react-native-chart-kit on react-native-svg.

The structure

Screens, components, hooks, navigation, services, store, theme, types and utils each live in their own folder. Notifications and storage sit behind small services instead of inside screens, and colours and spacing come from one theme module, so the light and dark themes stay consistent.

Status and limits

  • The code is public on GitHub. I haven't published the app to the Play Store or App Store.
  • The repository is named niyam-it; the app inside it is Habito.
  • Data stays on the device. There is no account or sync between devices.
  • There are no screenshots or tests in the repository yet.

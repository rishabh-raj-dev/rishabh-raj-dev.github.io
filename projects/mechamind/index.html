MechaMind Labs platform

Live siteJul 2025 – present · Team of about six

The learning platform behind MechaMind Labs, a robotics education company. I made the first commit in July 2025 and have contributed 187 of its 551 commits since, alongside a small team. It sells and delivers courses, runs workshop registrations, takes payments and issues certificates.

What it does

  • A public site for learning tracks, courses, workshops, seminars, projects and a blog.
  • An LMS: learner accounts, enrolled courses with chapters and lessons, a course video player, progress, submissions and certificates with a public verification page.
  • Workshop and cohort registration with Razorpay payments and coupons.
  • An admin console for courses, lessons, enrolments, workshops, registrations, notifications and support.

What I built

The repository is shared, so this is the part that is mine, read from my own commits:

  • The first version of the site: the Next.js app, home page sections, about, contact, pricing and the legal pages.
  • Admin and LMS API routes in the App Router, and the admin layout and login.
  • The course video player in the LMS.
  • The Razorpay integration for paid content.
  • Middleware that protects the admin and learner areas.
  • E-mail notifications through the Gmail API and SMTP (service account and app-password paths), plus newsletter and workshop notification endpoints.

How it is built

App
Next.js App Router, React, TypeScript, Framer Motion.
Data
Supabase (Postgres, auth helpers, storage), with row-level security policies maintained in SQL migrations.
Payments
Razorpay.
Content
TipTap rich-text editor for the blog and course content; PDF rendering for course material and certificates.
Mail
Gmail API with a Google service account, SMTP and Resend.
Deploy
Vercel, with a GitHub Actions workflow for preview deployments.

Status and limits

  • This is team work. The biggest share of commits belongs to other developers; the list above covers only what I wrote.
  • The code is in a private repository, so there is no public code link.
  • I haven't published traffic, revenue or learner numbers.
